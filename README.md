# 🛠️ LuccaTech Support - Sistema de Helpdesk

Sistema web para gestão e registo de chamados de suporte técnico, desenvolvido em PHP com persisência em base de dados MySQL.

🌐 **Demonstração Online:** [http://luccatech-helpdesk.ct.ws](http://luccatech-helpdesk.ct.ws)

---

## 🚀 Tecnologias Utilizadas

- **PHP** (Conexão via PDO com tratamento de exceções)
- **MySQL / phpMyAdmin**
- **HTML5 & CSS3** (Interface responsiva)
- **JavaScript**

---

## 📌 Funcionalidades

- [x] Registo e autenticação de utilizadores
- [x] Abertura de novos chamados de suporte
- [x] Listagem e consulta de tickets registados
- [x] Atualização de estado do chamado
